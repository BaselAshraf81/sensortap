## Test suite coverage

The automated Test_Suite (including the Conformance_Check in `sensortap/adapters/conformance.py`) validates schema compliance, sensor id stability, and the adapter-facing error contract. It does **not** cover, and cannot substitute for manual/hardware verification of:

- physical hardware readings (whether reported values match reality)
- per-vendor driver behaviour
- OS permission prompts
- Stream stability beyond 60 seconds
- performance/throughput benchmarking
